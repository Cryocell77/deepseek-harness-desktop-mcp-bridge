# v0.2.1-rc3

- Add DSH Desktop **0.2.1-rc.3**, Cordis **4.0.5** and Schemastery **3.18.5** support.
- Retain the three earlier supported Desktop combinations.
- Update Zod to **4.6.7** to address GHSA-mrhx-c7xc-m3w5.
- Update the portable Codex plugin, Desktop adapter and setup diagnostics.

Available from [GitHub Releases](https://github.com/Cryocell77/deepseek-harness-desktop-mcp-bridge/releases/tag/v0.2.1-rc3) and [npm](https://www.npmjs.com/package/dsh-desktop-mcp-bridge/v/0.2.1-rc3) (`next` channel).

See the [validation record](../VALIDATION.md) for test coverage and remaining live Desktop checks.
