# v0.2.2-rc1

- Support DSH Desktop **0.2.2-rc.1**, Cordis **4.1.0** and Schemastery **3.19.0**.
- Retain all six earlier exact Desktop combinations.
- Verify live Desktop connection, model execution, follow-up deduplication, cancellation and session cleanup with the local package.
- Update compatibility tests for the separate official native tool executor and update development/CI to Node **>=24.9**.

Available from [GitHub Releases](https://github.com/Cryocell77/deepseek-harness-desktop-mcp-bridge/releases/tag/v0.2.2-rc1) and [npm](https://www.npmjs.com/package/dsh-desktop-mcp-bridge/v/0.2.2-rc1) (`next`). See [validation](../VALIDATION.md) for test coverage.
